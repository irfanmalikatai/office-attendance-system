1. Introduction

Office Attendance Monitoring is a workplace attendance and activity monitoring solution designed to help organizations record employee attendance and measure website usage during work sessions.

This Privacy Policy explains the information processed by the Office Attendance Monitoring browser extension and its associated desktop application.

2. Information We Collect

During monitored work sessions, the browser extension may process the following information:

  • Active website domains.
  • The extension processes active website domains during attendance sessions. It sends the normalized website domain only, not full URLs, page paths, query parameters, or URL fragments.
  • Browser tab activity and website navigation events.
  • Website usage information used to calculate activity duration.
  • Website access restriction policies supplied by the desktop application.

The associated attendance system may link activity records to an employee account or attendance session.

The extension reads the active tab URL locally to identify its normalized website domain. Domain activity messages do not include full URLs, page paths, query parameters, or URL fragments.

3. How Information Is Used

Information is processed for the following purposes:

  • Recording website usage during work sessions.
  • Calculating time spent on websites.
  • Supporting employee attendance and activity reports.
  • Providing authorized administrators with workplace activity information.
  • Applying organization-defined website access restrictions.
  • Maintaining the operation of the attendance monitoring system.

4. Browser Extension Permissions

The extension requests browser permissions needed for its monitoring and website policy functions.

  • Tabs: Identifies active browser tabs and website URLs.
  • WebNavigation: Detects website navigation events.
  • NativeMessaging: Communicates with the locally installed Office Attendance desktop application.
  • Alarms: Schedules periodic activity checks and policy expiration tasks.
  • DeclarativeNetRequest: Applies configured website access restrictions.

5. Monitoring Sessions

Office Attendance Monitoring is intended to associate website activity with authorized employee attendance sessions between Check In and Check Out.

The browser extension communicates with a local desktop agent responsible for validating attendance session status.

Employees should receive clear notice of monitoring and applicable workplace policies before using the system.

6. Data Sharing and Access

Website activity information is transmitted from the browser extension to the locally installed Office Attendance desktop application.

Depending on the organization's deployment, the desktop application may process or transmit attendance records to an administrative reporting system.

Authorized organization administrators may access employee activity information for attendance management and workplace reporting.

The extension is not intended to sell personal information or use employee activity information for advertising.

7. Data Retention

The intended retention policy is to keep employee attendance and website activity records until an authorized organization administrator deletes them.

Consequently, records may be retained indefinitely unless deleted. Actual deletion and retention practices depend on the organization's configured attendance system and applicable legal requirements.

8. Data Security

The browser extension communicates with the locally installed desktop application through Chrome's native messaging interface.

Organizations operating the attendance system are responsible for securing their administrative accounts, stored records, servers, and data transmission infrastructure.

No electronic storage or transmission method can guarantee absolute security.

9. Employee Privacy

Office Attendance Monitoring is intended for transparent, authorized workplace monitoring.

The extension is not designed to read webpage message bodies, passwords entered into forms, or keystrokes.

However, URLs may contain sensitive information, including search terms or identifiers.

Organizations must provide appropriate employee notice and comply with applicable privacy, employment, and data protection laws.

10. Data Access and Deletion Requests

Employees may contact their organization administrator to request information about their attendance records or request correction or deletion where applicable.
